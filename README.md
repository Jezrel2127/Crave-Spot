# Crave Spot

## Project Description
Crave Spot is a website prototype that enables clients to browse food and drinks, perform a search within the menu, manage the shopping cart and experience the demo checkout process.

## Objectives
- Offer a convenient food ordering interface.
- Enable users to browse the food and drinks.
- Offer menu searching and sorting by categories.
- Let the user add, edit and delete the items in the cart.
- Show the checkout process in a prototype.

## Main Features
- Food and Drinks menu tabs
- Categories and searching within the menu
- Shopping cart and item quantity control
- Delete the items from the cart
- Login and Sign-Up demo interfaces
- Checkout demo
- Browser storage in case of its implementation in the current code

## Used Technologies
- HTML
- CSS
- JavaScript
- Visual Studio Code
- Figma – user interface prototyping

## Project Structure
- `index.html` – website structure
- `style.css` – website design
- `script.js` – website functionality
- `README.md` – project documentation

## How to Run the Project
1. Open the project directory in Visual Studio Code.
2. Open `index.html` file in a web browser or using the Live Server extension in case you have it installed.
3. Explore the menu and enjoy the website's functionality.

## Limitations

Currently Crave Spot is a prototype site. Checkout in the demo does not take actual payments. Authentication and other backend functionalities cannot be assumed to be real until implemented and integrated.
